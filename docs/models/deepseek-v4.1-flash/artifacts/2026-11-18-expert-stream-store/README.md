# Model-neutral expert store (E124)

`replay-arms.json`: the 53-request Pi coding-agent replay on streamed
`UD-IQ2_XXS` with the `MXFP8` Engram, DSpark and vision, one fresh server per
arm. Replies are recorded as SHA-256 prefixes with the per-run tool-call ids
removed; prompts and replies are left out.
